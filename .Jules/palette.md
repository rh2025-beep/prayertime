## 2024-05-18 - Missing ARIA Labels on High-Frequency Modals and Action Buttons
**Learning:** This application uses highly dynamic, full-screen React modals for essential features like Settings, Qibla Compass, and Location Search. However, the wrapper elements (`<div className="fullscreen-view">` and `<div className="modal-content">`) lacked the fundamental `role="dialog"` and `aria-modal="true"` attributes. The main headings also lacked an ID to pair with an `aria-labelledby` property. Additionally, many critical interactive elements (like the search submission button or calibration dismiss icon) were icon-only and completely opaque to screen readers because they lacked `aria-label`s.
**Action:** Always ensure that custom modal wrapper components receive standard ARIA dialog attributes (`role`, `aria-modal`, `aria-labelledby`) and double check all icon-only interactive elements (like `<Search />`, `<RefreshCw />`, and `<Locate />` buttons) to guarantee they are accompanied by a descriptive `aria-label`, potentially falling back to existing localization strings (`str.searchBtn` etc.).
