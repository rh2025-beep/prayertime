## YYYY-MM-DD - [Async Feedback Loading States]
**Learning:** Native device API integrations like `navigator.geolocation` can be slow, making users think the app is unresponsive if there's no visual feedback.
**Action:** Always wrap async device API calls in state variables and add visual feedback, like `.spin-icon`, to trigger buttons.
