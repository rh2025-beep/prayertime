## YYYY-MM-DD - Search Input Accessibility and Feedback
**Learning:** In interactive lists (like search results), using `div` with `onClick` handles pointer events but breaks keyboard navigation and screen reader support. Converting them to `button type="button"` and ensuring layout styles (like `textAlign: left`, `width: 100%`) are maintained improves accessibility significantly. Additionally, async actions without visual feedback (like the location search) benefit greatly from disabled states and spinning icons to prevent user confusion.
**Action:** Always check for interactive `div` elements in map/list renders and convert them to semantic `button` tags with proper layout styling. Apply disabled states and loading indicators to buttons triggering async network requests.
