## 2024-06-25 - Prevent High-Frequency DOM and I/O Operations in React Interval Loops
**Learning:** Instantiating `Intl.DateTimeFormat` dynamically within a 1-second interval loop (such as for timer and clock features) blocks the main thread with unnecessary overhead. Also, synchronous disk I/O via `localStorage.setItem` and native Capacitor plugin calls inside such high-frequency intervals severely impact performance, particularly when the underlying payload doesn't change every second.
**Action:** Always memoize expensive objects like `Intl.DateTimeFormat` using `useMemo` (or similar) outside the loop when they depend on values (e.g., timezone strings) that update infrequently. Furthermore, implement a dirty-checking mechanism with `useRef` to stringify and verify payloads before writing them to disk (`localStorage`) or crossing the native bridge in Capacitor.
