## YYYY-MM-DD - [Optimize 1-Second Render Thrashing in App]
**Learning:** Found two 1-second interval performance bottlenecks: 1) Dynamically instantiating `Intl.DateTimeFormat` with `toLocaleString` causes excessive CPU load. 2) Synchronous disk I/O (`localStorage.setItem`) and Native Bridge calls (`Capacitor.Plugins.PrayerWidget.updateWidget`) triggered every second because derived UI state like "time left" updates frequently.

Introduce a `useRef` for dirty-checking state payloads passed to Capacitor native plugins, ensuring all independent state variables (like colorTheme and widgetStyle) are included in the comparison to skip unnecessary native/bridge/disk operations.
