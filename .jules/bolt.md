## 2024-10-24 - Avoid expensive formatters and synchronous disk I/O in high-frequency React interval loops
**Learning:** Calling `new Date().toLocaleString` inside high-frequency interval loops (e.g. 1-second timers) blocks the main thread because `Intl.DateTimeFormat` initialization is extremely expensive (~0.4ms vs ~0.006ms for a cached instance). Additionally, writing to `localStorage` unconditionally inside these loops causes synchronous disk I/O, worsening the main thread blocking.
**Action:** Always memoize expensive formatters like `Intl.DateTimeFormat` (or `toLocaleString`) outside the loop or via React's `useMemo`. When writing to `localStorage` inside frequent intervals, use `useRef` to dirty-check the stringified value against the previously saved value to prevent unnecessary disk I/O operations.
