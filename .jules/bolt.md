## 2026-09-15 - React Render Performance with Intl.DateTimeFormat
**Learning:** In React components that render frequently (e.g. a clock ticking every second), creating `Intl.DateTimeFormat` inside the render function or a tight loop is a massive performance bottleneck. `Intl.DateTimeFormat` takes >3000ms for 10000 iterations compared to ~40ms when memoized/cached, and 1088ms for `toLocaleString`. This causes heavy CPU usage, battery drain, and dropped frames, especially on mobile where Capacitor apps run.
**Action:** Always memoize `Intl.DateTimeFormat` instances (e.g., using a custom hook like `useTzFormatter` with `useState`/`useEffect` or simply wrapping it outside the render loop if stateless) and reuse them with `.format()` rather than instantiating them on every render or falling back to `toLocaleString` with `timeZone` options.
