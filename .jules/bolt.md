## 2026-09-07 - React 1-Second Interval Optimizations
**Learning:** In React components with high-frequency timers (like `setInterval` calling state updates every second), invoking expensive formatters like `Date.toLocaleString` inside the render function or dependency-heavy `useEffect`s causes significant main-thread lag. Additionally, synchronous disk I/O (`localStorage.setItem`) inside these tick-based effects blocks the thread if not dirty-checked.
**Action:** Always memoize expensive formatters (e.g., `Intl.DateTimeFormat`) using `useMemo` with timezone configurations (using `hourCycle: 'h23'` for correct parsing). For effects handling side-effects like disk I/O or native Capacitor calls on every tick, use a `useRef` variable to cache stringified payloads and early-return if the data hasn't changed.
