## 2024-08-19 - 1-Second Tick Loop synchronous I/O and String Parsing
**Learning:** React component re-renders or `useEffect` hooks that fire every second (e.g., from a ticking clock) can cause severe performance bottlenecks if they contain synchronous disk I/O (like `localStorage.setItem`) or expensive string parsing operations (like `Date.prototype.toLocaleString` with `timeZone` options). Benchmarks show `toLocaleString` takes ~2.2s for 10k calls, while a cached `Intl.DateTimeFormat` takes only ~30ms. Furthermore, writing to `localStorage` un-debounced every second locks the main thread and drains battery.
**Action:** Always memoize `Intl.DateTimeFormat` for timezone conversions instead of using inline `toLocaleString`. For side effects like saving state or syncing widgets in a fast tick loop, use a `useRef` to track the serialized payload and only perform the actual write/sync when the payload changes.
